# FlappyBron

A basketball themed twist on Flappy Bird, built in Java, where you guide LeBron through NBA team themed obstacles.

## Project Goal

FlappyBron is a basketball themed twist on the classic mobile game Flappy Bird. As a lifelong basketball fan and player from the Philly area, I wanted to create a project that combines my passion for basketball and the 76ers with my interest in game development. With LeBron now playing for Philly, I thought it would be fun to build a game centered around him. Players will control a flying LeBron face and navigate through gaps between obstacles themed around his former and current teams.

## MVP Scope

The first version of FlappyBron will include:

- A LeBron character that players control by pressing Space to jump
- Colorful, team themed obstacles featuring the Cavs, Heat, Lakers, and 76ers
- A scoring system and collision detection
- A start screen and the ability to restart after losing

The goal is to build a fully playable game with the core mechanics working before adding extra features.

## Future Plans (V2.0+)

If time allows, I plan to add:

- A local leaderboard displaying the top player scores
- Background basketball themed music and sound effects
- Multiple difficulty levels that make the game progressively harder
- Additional animations and visual effects

## Tech Stack

- **Language:** Java
- **Graphics and game window:** Java Swing and AWT
- **Game mechanics:** Swing Timer for the game loop, keyboard input handling, and Java classes such as ArrayList and Random
- **Assets:** Local image files for the player, obstacles, and backgrounds
- **Future features:** Java file I/O for saving leaderboard scores and javax.sound.sampled for music and sound effects

The game will be developed as a Java desktop application.
